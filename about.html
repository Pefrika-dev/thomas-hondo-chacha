01Who I am

A builder with an eye for the whole picture.

I work across software engineering with a focus on front-end development and practical web systems. I enjoy the part where a real problem becomes a clear interface: structuring content, shaping interactions and making sure the result behaves well on every screen.

My foundation is semantic HTML, responsive CSS and vanilla JavaScript. When a project needs server-side logic, I work with Node.js, Express and PostgreSQL, and I connect interfaces to supported APIs where it makes sense.

I'm not interested in showing off the longest list of technologies. I choose tools that suit the problem and place the emphasis on clarity, accessibility and code that can be maintained.

03How I approach projects

Thoughtful decisions, not decoration.

Understand before building

Simplify the path
